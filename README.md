# Abahiriwe Creators

Website for [abahiriwe.com](https://abahiriwe.com), the monthly creator competition for young people based in Rwanda, run by Teebah Media Village.

- `index.html` is the whole site (single page, no build step).
- Hostinger deploys this repository automatically to `public_html` on every push to `main`.
- The application form link lives in one place near the bottom of `index.html`: `APPLICATION_FORM_URL`.
